# Design guidelines (to be supplied by the owner)

**Status: not written yet.** The owner will supply this document (P41). Until it exists, the
frontend follows `design-system.md` and keeps every visual choice in design tokens, so the
guidelines can be applied in one place when they arrive.

When present, this document **overrides `design-system.md`** wherever they differ. Things it is
expected to settle:

- the typeface (open: JetBrains Mono is the fallback, Q31 on long prose in monospace);
- colour palette, accent, and the light/dark themes;
- spacing, density and the sheet's row height;
- reference screens or mockups (app shell, BoQ sheet, line detail, setup wizard, share page);
- icon set and when icons are used;
- tone of voice for UI text.

An agent that needs a visual decision this document doesn't cover asks the owner rather than
inventing a style.
